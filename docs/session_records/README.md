## 3. 本次会话解决的问题与实现功能回顾

### 1) 瓶子倒满后高度溢出/暴涨又回落的 Bug 修复
- **原因分析**:
  1. 在 `src/App.tsx` 的倒水返回阶段（`returning`），由于未显式重置 `riseCount` 与 `drainCount`，导致其在 `result.newTubes` 状态已经提交后仍保留为 0.85/当前倾倒量，从而在目标瓶已有的 4 格液体上又叠加上了未清除的动态液体层（达 4.85 格），超出瓶身冲出瓶口。
  2. 原 `TestTube.tsx` 中的标准状态渲染组件 `<g>` 未加 `clipPath`，使得溢出层未被限制在玻璃瓶腔体内。
  3. 倒水阶段结束后 `pourAnimation` 销毁时，额外层瞬间消失，造成玩家看到的“先暴涨溢出、后突然回落”的现象。
- **修复方案**:
  - `src/App.tsx`: 在 `returning` 阶段严格重置 `drainCount: 0, riseCount: 0`。
  - `src/components/TestTube.tsx`:
    - 支持精确的多格液体倾倒与充盈过渡。
    - 增加严格的高度钳制 `accumulatedUnits <= capacity (4)`，任何情况下液体绝不超出瓶身有效高度。
    - 在静止与堆叠状态 `<g>` 外层统一加上 `clipPath={url(#inner-clip-${index})}`，液体物理上被锁在瓶体腔内。

### 2) 倾倒时 `drainingTopPercent` 运行时错误修复
- **原因分析**: 在重构液体渲染层时，倾倒时的水流面滑动计算遗留了对未声明变量 `drainingTopPercent` 的引用，导致倒水时抛出 `ReferenceError: drainingTopPercent is not defined`。
- **修复方案**: 改为基于 `sourceDrainingCount` 动态计算各色块水流收缩百分比 `runUnits = displayTube.length - runStartIdx; drainPct = Math.max(0, 1 - (sourceDrainingCount / Math.max(1, runUnits)));`。

### 3) 瓶子倒满仪式感特效（木塞下落 -> 粒子旋转 -> 飞入对应颜色购物袋）
- **木塞降落**: 瓶子集满时，从顶部以弹性加速度降下 3D 木质塞子并栓入瓶口，带有 `playCorkPop()` 音效。
- **粒子旋涡**: 瓶身周围环绕 8 颗金色星芒粒子，呈 3D 螺旋轨迹旋转升腾，瓶身呼吸发光。
- **飞入购物袋**: 计算从试管插槽到顶部对应颜色购物袋的精确物理向量坐标，瓶身平滑缩放并飞入袋内。
- **购物袋吞入反应**: 购物袋产生弹性饱腹吞咽反馈（`anim-bag-gulp`），并在透明视窗中收纳显示对应的迷你软木塞药水瓶，伴随 `playBagCatch()` 收集音效。

### 4) 水位平滑缓慢上升与真实物理倒水音效
- **接受瓶水位缓慢上升**: 将原有瞬时跳变的 `riseCount` 与 `drainCount` 重构为基于 `requestAnimationFrame` 的流体 S 曲线（EaseInOut）渐进式动画循环（~1000ms），接受瓶液体逐像素平滑升起，倾倒瓶液体同步向下回缩，落水点实时跟随液面同步上浮。
- **依据水位的真实倒水音效（动态空腔物理咕嘟声）**:
  - 重构 `SoundManager.playDynamicPour(startVolume, pourCount, capacity)`。
  - 加入随液体上升实时升调的 **级联气泡爆破音阶（Cascading Glug-Glug Pulses）**（空瓶底深沉咕嘟声 250Hz -> 随注满逐步爬升至 950Hz 清脆水花声）。
  - 结合粉红噪音流动声与动态扫频带通共鸣滤波，真实模拟水流入瓶时空气柱缩短的声学物理现象。

### 5) 细致水花溅射与水面微波涟漪重构
- **剔除粗糙大球状伪水泡**: 移除了原有生硬笨拙的 4 个大黄色实心圆圈与粗黑边框。
- **新增三层高精流体撞击特效**:
  1. **水面同心椭圆涟漪波纹（Concentric Surface Ripples）**: 3 层随相位向外舒展扩散并半透明淡出的液面微波。
  2. **细腻微泡沫冠（Micro-Froth Crown）**: 7 颗带有高光微核、微透光泽的轻盈微气泡簇（半径 1.5px - 3.2px，无粗边框）。
  3. **动态飞溅微水滴微粒（Airborne Droplets Arc）**: 抛物线重力向上喷涌并自然回落的细腻微水珠粒子阵列。

### 6) 底部液体视觉高度补偿与倾倒时底层非倒出液体重力倾角重构
- **底部颜色视觉高度补偿**:
  - 原几何中，瓶底由 $y=130 \to 138$ 的 8px 内凹圆弧穹顶和圆柱侧壁组成。原设计为固定 27.5px 高度，导致底层有效直立侧壁仅 $130 - 110.5 = 19.5\text{px}$，相比上层 27.5px 缩水近 30%，视觉上呈现明显的“底层偏矮偏短”问题。
  - 重构后引入流体视觉体量补偿函数 `getBlockNominalHeight` 与 `getBoundaryY`：
    - 底层名义高度设为 33.0px（侧壁有效直立高度 $130 - 105 = 25.0\text{px}$ + 8px 瓶底穹顶）。
    - 上层三格平分剩余 77px（每格名义高度 25.67px，有效直立侧壁 25.67px）。
    - 四格色块的直立侧边轮廓完全一致（25.0px vs 25.67px），且 4 格注满时正好达 $y = 28$ 瓶肩线，彻底消除视觉高矮落差。

### 7) 倾倒试管物理流体动力学全面重构（纠正重力反向与实心塞满问题）
- **根因彻底清查**:
  - 原倾斜渲染模型错误地将试管局部坐标系的位移方向混淆，导致倾斜倒水时：底层未倒出液体被赋予了靠近天花板侧壁（高侧壁）的偏移，呈现“反重力漂浮在瓶顶”的严重常识性错误；且倾倒上层液体被绘制成塞满天花板侧壁的大块实心多边形，不仅挤压导致红黄层级颠倒，还造成整瓶液体体积视觉暴增、上方无空气气室。
- **全新真实流体力学几何建模**:
  1. **双向重力墙与天花板空腔自适应**：
     - 精确根据旋转角度正弦值 $\sin(\theta)$ 确定真正的地心引力侧壁（`floorX`）与朝天气室侧壁（`ceilingX`）。
     - 底层液体（如红色）严格汇集并平淌在**地面低侧壁与最低底角**，高侧壁自然退落露出空腔，彻底消除“反重力浮空”。
  2. **红黄两层液体层级还原**：
     - 底层液体垫在最低处，上层倾倒流体沿着底层液体的倾斜月牙曲面自然滑向瓶口，两者在重力作用下呈现正确的分层浮动关系。
  3. **真实倾倒水流与开阔空气气室**：
     - 倾倒层从瓶口出水唇沿（`floorSpoutX`）向内收缩为真实的**流束（Viscous Stream）**，仅贴着靠地的低侧壁流动；
     - 瓶身上方的朝天侧壁保留**完整通透的空气腔**，气液自由表面带有微曲高光（Wave Specular Highlight），绝不再出现“被咬一口的实心黄胶块”或体积暴增现象；
     - 随着倾倒进度 `drainPct` 实时收窄流束，流体在低壁呈现高光流速线条，与外部垂直下落的水流实现无缝衔接。
